# 🚀 JobQuest AI

AI-powered gamified job analyzer built to help candidates optimize resumes and improve job matching.

## ✨ Features

- 📄 Resume PDF upload
- 🎯 Job description analysis
- 📊 Match score dashboard
- ⚡ Skill gap analysis
- 📅 7-day improvement roadmap
- 🎮 Gamified UI experience
- 🌌 Cyberpunk-inspired design

## 🛠 Technologies

- HTML5
- JavaScript
- Tailwind CSS
- PDF.js
